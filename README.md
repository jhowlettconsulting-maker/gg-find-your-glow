# Find Your Glow

Glow Getter Collective’s responsive “Find Your Glow” HTML widget.

## Files

- `gg-find-your-glow-responsive.html` — the supplied widget, exported from the open browser attachment.
- `index.html` — an identical copy for a static host’s default page.

Open either HTML file in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

The HTML includes its JavaScript and styles. Its Google Fonts link requires internet access. Booking links and widget behavior are preserved from the supplied source.

The browser extension’s body class and Codex overlay element were removed from the export. No widget logic or design was changed. Runtime behavior has not been verified.
